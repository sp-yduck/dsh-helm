dsh issues a new launch token on every start. Get the login URL with:

  kubectl -n {{ .Release.Namespace }} logs deploy/{{ include "dsh.fullname" . }} | grep token=

{{- if .Values.ingress.enabled }}

Open it via https://{{ (first .Values.ingress.hosts).host }}/?token=<token>
{{- else }}

To open the UI from your machine, forward the port and open the printed URL:

  kubectl -n {{ .Release.Namespace }} port-forward deploy/{{ include "dsh.fullname" . }} 3080:3080

For access from other machines, enable the Ingress with TLS.
{{- end }}
